Entry for the [Funniest Autocorrect Fail](https://make.fun/c/u-zeroxfive-funniest-autocorrect-fail-ddf82154) bounty on make.fun ($2).

## What it does

`main.ts` writes exactly one line — a hilarious autocorrect fail, 123 characters — to `/output/entry.txt`:

> Texted my wife 'pick up milk on your way home' — autocorrect changed it to 'pick up Mike' and now Mike is coming to dinner.

## Run

```sh
node main.ts
```

Requires Node 22 or later. Deterministic: every run writes the same bytes.
